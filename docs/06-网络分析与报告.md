# 06 — 网络分析 与 报告（M3）

> 本阶段在 M1 核心循环稳定后再实现，但数据模型与接口已在 01/04 预留。

## 1. 网络构建

- **节点**：全网络去重后的词（含种子词）。
- **边三类**：
  - `association`：联想路径（时序相邻）
  - `semantic`：embedding 相似度 ≥ 阈值的词对
  - `emotion`：同情绪类 / 同情绪主题的词对
- **在线状态**：网络随联想实时更新，派生 `network_state`（质心/核心词/情绪分布/社区），
  同时被「评分」（02）与「候选生成」（05）读取——三者共享同一结构观，而非仅在结束时才建网。

## 2. 分析指标（networkx）

- **社区发现**：Louvain 算法，识别「相似颜色聚在一起的集群」。
- **中心度**：degree / betweenness / eigenvector，识别「小球围绕的大球」。
- **情结候选**：满足以下条件的节点/子图：
  1. 综合分 `total` 高；
  2. 中心度高（被反复关联）；
  3. 反应时异常（`rt_zscore` 显著为正）；
  4. 情绪强度高。

## 3. 可视化映射（M2）

| 属性 | 视觉映射 |
|---|---|
| 词 | 小球（节点） |
| 情绪类型 | 小球颜色（见 03） |
| 综合分/强度 | 小球大小（`size = 8 + 16·total`） |
| 联想路径 | 一种连接颜色 |
| 语义相似 / 情绪脉络 | 另一种连接颜色 |
| 集群 | 相似颜色聚拢，小球围绕大球（核心词）转 |

## 4. 报告生成

- 输入：网络统计 + 节点四维评分 + 情结候选 + 反应时异常列表。
- 由 LLM 生成自然语言解读（各情结候选的主题、可能关联、情绪基调）。
- 输出结构见 [04-API 的 /report](./04-API接口.md)。

### 伦理声明（必须附在每份报告）

> 本报告由探索性自省工具自动生成，仅用于自我觉察与反思参考，**不构成任何临床诊断或专业建议**。

## 5. 后续可扩展

- 多次会话纵向对比（同一用户的情结演化）。
- 反应时异常的精细分类（复述/误解/躯体反应等荣格「干扰征象」，需更多输入信号）。
