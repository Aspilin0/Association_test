# 01 — 数据模型

所有结构以 JSON 传输，后端用 Pydantic 校验，前端用对应的 TypeScript 类型。

## 1. 情绪类型枚举 `EmotionType`

```
joy | trust | fear | surprise | sadness | disgust | anger | anticipation | neutral
```

## 2. WordNode（联想词节点）

一个词在「全网络」中是唯一的（跨链去重），但同一词可以 `occurrences > 1`。

```json
{
  "id": "uuid",
  "text": "房子",
  "emotion_type": "sadness",
  "emotion_intensity": 0.72,

  "scores": {
    "emotion": 0.72,
    "similarity": 0.31,
    "connectivity": 0.0,
    "reaction_time": 0.85,
    "total": 0.61
  },

  "reaction_time_ms": 1234,
  "rt_zscore": 1.2,

  "order": 5,
  "source": "selected",
  "is_back": false,
  "occurrences": 1,
  "seed_of": "家",
  "created_at": "2026-09-16T12:00:00Z"
}
```

字段说明：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 全局唯一 id（同词复用同一 id） |
| `text` | string | 词语文本 |
| `emotion_type` | EmotionType | LLM 标注的情绪类 |
| `emotion_intensity` | float 0~1 | 情绪强度 |
| `scores` | object | 四维评分 + 综合分（见 02） |
| `reaction_time_ms` | int \| null | 反应时（ms），自由输入/选择均有 |
| `rt_zscore` | float \| null | 反应时相对个人基线的 z 分数 |
| `order` | int | 在该链内的次序（1-based） |
| `source` | `selected` \| `free` | 选择候选 / 自由输入 |
| `is_back` | bool | 是否为历史已出现词 |
| `occurrences` | int | 该词累计出现次数 |
| `seed_of` | string | 所属种子词 |
| `created_at` | string | ISO 时间 |

## 3. Edge（边）

```json
{
  "id": "uuid",
  "from": "word_id_a",
  "to": "word_id_b",
  "type": "association",
  "weight": 1.0
}
```

- `type` 三选一：
  - `association`：联想路径（前后相继的词，时序连接）
  - `semantic`：语义相似（embedding 相似度超过阈值）
  - `emotion`：情绪脉络（同情绪类 / 同情绪主题）
- 同一对节点可有多条不同类型的边；重复出现会提高 `weight`。

## 4. Session（实验会话）

```json
{
  "id": "uuid",
  "seed_words": ["家", "母亲"],
  "options": {
    "rounds_per_seed": 10,
    "candidate_count": 8,
    "temperature": 0.9,
    "emotion_scheme": "plutchik",
    "llm_provider": "deepseek"
  },
  "status": "running",
  "created_at": "...",
  "finished_at": null,

  "chains": [
    { "seed": "家", "node_ids": ["n1", "n3", "n5"] },
    { "seed": "母亲", "node_ids": ["n2", "n4"] }
  ],

  "nodes": { "n1": { "...WordNode" } },
  "edges": [ { "...Edge" } ],

  "history": ["家", "房子", "母亲"],
  "baseline": { "mean_rt_ms": 1500, "std_rt_ms": 500, "n": 0 },
  "network_state": { "...见 6. network_state" }
}
```

字段说明：

| 字段 | 说明 |
|---|---|
| `chains` | 每个种子一条链，`node_ids` 为该链按时间排序的词 |
| `nodes` | 全网络节点表（跨链去重） |
| `edges` | 全网络边列表 |
| `history` | 已出现词语（按时间，含种子），用于 back 判定 |
| `baseline` | 个人反应时基线（均值/标准差/样本数），随提交更新 |
| `network_state` | 在线网络状态摘要（质心/核心词/情绪分布/社区），评分与候选生成共享 |

## 5. Options（默认值）

| 字段 | 默认 | 说明 |
|---|---|---|
| `rounds_per_seed` | 10 | 每条链的联想轮数 |
| `candidate_count` | 8 | 候选池大小（6~8） |
| `temperature` | 0.9 | LLM 候选生成温度（高=多样） |
| `emotion_scheme` | `plutchik` | 情绪分类体系 |
| `llm_provider` | `deepseek` | LLM 提供方（可插拔） |

## 6. network_state（在线网络状态）

随联想实时更新的网络摘要，**被评分（02）与候选生成（05）共享**，保证二者在同一个「结构观」下工作：

```json
{
  "node_count": 12,
  "centroid_words": ["家", "房子"],
  "dominant_emotion": "sadness",
  "emotion_distribution": { "sadness": 4, "joy": 2 },
  "top_central_words": ["房子", "家"],
  "communities": [
    { "id": 0, "centroid_words": ["家", "房子"], "dominant_emotion": "sadness" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `node_count` | 已出现去重词数 |
| `centroid_words` | 距全局质心最近的若干词（代表全局结构中心） |
| `dominant_emotion` | 主导情绪类 |
| `emotion_distribution` | 各情绪类词数分布 |
| `top_central_words` | 度数中心度最高的核心词（潜在情结核心） |
| `communities` | Louvain 社区（M3 计算，M1 可为空数组） |
