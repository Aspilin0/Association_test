# 联想情结探测工具 — 设计总览

> 精神分析学派「词语联想实验」+ 荣格情结理论 的 AI 增强实现。
> 通过「种子词 → 候选联想 → 反应时 → 多维评分 → 潜意识网络 → 分析报告」来探测联想链背后的情绪敏感点（潜在情结）。

## 1. 定位与边界

- **性质**：探索性 / 自省型工具，**非临床诊断**。所有报告必须附带该声明。
- **输入**：1 个或多个种子词。
- **主路径**：候选词选择为主，自由输入为辅。
- **输出**：潜意识网络数据 + 可视化 + 分析报告。

## 2. 核心循环

```
[输入种子词] → 生成候选池(6~8) → 渲染候选 + 开始计时
   → 用户选择候选 / 自由输入(回车) → 停表记录反应时(RT)
   → 四维评分(情绪值/相似度/连接量/反应时) → 更新联想链
   → 生成下一轮候选(含 back 惩罚) → 循环…
   → 终止 → 汇总潜意识网络 → 可视化 → 分析报告
```

## 4. 技术栈

- **前端（M1 实际）**：免构建原生 HTML/JS/CSS（后端直接托管）；目标 React + Vite + D3（联网后）
- **后端（M1 实际）**：Python `aiohttp`（异步，环境已内置）；目标 FastAPI（联网后）；`networkx` 做网络分析（M3）
- **LLM**：可插拔（默认 DeepSeek API，预留 Ollama，无 key 自动回退 mock）
- **Embedding**：默认字符 n-gram（离线占位），可切 API（OpenAI 兼容）
- **存储**：M1 单进程内存，后续接 SQLite

## 5. 里程碑

| 阶段 | 范围 | 交付物 |
|---|---|---|
| **M1** | 核心实验循环 | 后端：会话/候选/评分；前端：种子输入页 + 实验页 + 文本结果页 |
| **M2** | 网络可视化 | 力导向图：小球(词) + 情绪颜色 + 大小(评分) + 三类连接 |
| **M3** | 分析与报告 | 社区发现、情结识别、LLM 报告生成 |

## 7. 待校准项（实现中通过实验确定）

1. 评分四维的默认权重 `0.40 / 0.25 / 0.15 / 0.20`。
2. 反应时初始基线 `μ=1500ms, σ=500ms` 与更新系数。
3. back 机制的候选排序惩罚系数（默认 ×0.5）。
4. 相似度与候选生成均面向「全局网络结构」（种子词与上一词权重最高），评分与生成共享在线网络状态——见 [02-评分模型](./02-评分模型.md) 与 [05-候选词与back机制](./05-候选词与back机制.md)。
