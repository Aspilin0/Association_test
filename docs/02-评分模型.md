# 02 — 评分模型

每个联想词产出四维评分（各归一化到 0~1），再合成综合分 `total`。

**核心原则**：反应时是信度最高的信号（荣格原版的核心指标），综合分以其为锚，其余三维作为辅助证据。

## 1. 反应时 `reaction_time`

个人基线 + z 分数归一化：

```
z = (rt − mean) / max(std, 100)        # std 下限 100ms 防止除零
reaction_time_score = 1 / (1 + e^(−z)) # sigmoid，z=0 → 0.5
```

- **初始基线**：`mean=1500ms, std=500ms`（默认，可配）。
- **更新**：每次提交后用指数移动平均更新，样本数 +1：
  ```
  mean ← α·rt + (1−α)·mean        (α = 0.2)
  var  ← α·(rt−mean)² + (1−α)·var
  ```
- **语义**：RT 显著高于个人平均水平 → 可能触及情结 → 高分。

## 2. 情绪值 `emotion`

```
emotion_score = emotion_intensity
```

- 由 LLM 标注（见 03）：输出情绪类 + 强度 0~1。
- `neutral` 的强度默认记 0（或由 LLM 给出接近 0 的值）。

## 3. 相似度 `similarity`（全局结构）

相似度衡量「新词融入当前潜意识网络」的程度——**不只看种子词，而是面向全局结构**，其中**种子词与上一词权重最高**，其余由全局结构贡献。

```text
similarity_score = 0.35·cos(w, seed)
                 + 0.35·cos(w, prev)
                 + 0.30·cos(w, centroid)
```

- `seed`：种子词 embedding；`prev`：上一词 embedding。
- `centroid`：全局网络质心（已有节点 embedding 的均值），代表「全局结构」。
- 三者均为余弦相似度（0~1）；权重默认 `0.35 / 0.35 / 0.30`，可配。
- 链上首词（无 `prev`）时，`prev` 的 0.35 权重临时并入 `centroid`（0.30→0.65）。

> 该「全局结构」项与候选词生成、网络聚类共享同一份在线网络状态（见 05、06），
> 保证评分与生成在同一个「结构观」下工作。更细可扩展为按近邻/社区的加权（M3）。

## 4. 连接量 `connectivity`

```
connectivity_score = degree / (degree + 1)
```

- `degree`：该词当前的连接数（入/出边数之和）。
- 重复出现（`occurrences > 1`）额外加成：`connectivity_score = min(1, base + 0.2·(occurrences−1))`。
- 采用 `degree/(degree+1)`：单调有界（0~1），避免小网络下 `mean_degree` 过小导致的饱和。

## 5. 综合分 `total`

```
total = 0.40·reaction_time
      + 0.25·emotion
      + 0.15·similarity
      + 0.20·connectivity
```

权重默认值，可配置；`total ∈ [0,1]`。

## 6. back 对评分的影响

- 历史词被再次选中/输入时：`is_back=true`，`occurrences += 1`。
- **重复是干扰征象（强信号）**：`reaction_time` 维度额外加成 `+0.1`，同时 `connectivity` 因 `occurrences` 上升而提高。
- 候选排序里的惩罚（×0.5）见 [05](./05-候选词与back机制.md)，与评分加成互不冲突：排序上"难被推荐"，但一旦被用户主动选择，则"更值得标记"。

## 7. 待校准项

- 四维权重 `0.40/0.25/0.15/0.20`。
- 相似度内部权重 `0.35/0.35/0.30`（种子 / 上一词 / 全局质心）。
- 基线初值 `μ=1500, σ=500`、更新系数 `α=0.2`。
- sigmoid 是否替换为分段线性（更易解释）。
