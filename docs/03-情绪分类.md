# 03 — 情绪分类

采用 **普拉奇克（Plutchik）情绪轮 8 类 + 中性** 共 9 类，由 LLM 动态标注（可插拔，后续可接词典兜底）。

## 1. 类别与颜色映射

颜色用于可视化（M2），可配置。

| 类型 | 中文 | 颜色 | HEX |
|---|---|---|---|
| `joy` | 快乐 | 黄 | `#FFD54F` |
| `trust` | 信任 | 浅绿 | `#9CCC65` |
| `fear` | 恐惧 | 紫 | `#AB47BC` |
| `surprise` | 惊讶 | 青 | `#26C6DA` |
| `sadness` | 悲伤 | 蓝 | `#42A5F5` |
| `disgust` | 厌恶 | 绿 | `#66BB6A` |
| `anger` | 愤怒 | 红 | `#EF5350` |
| `anticipation` | 期待 | 橙 | `#FFA726` |
| `neutral` | 中性 | 灰 | `#BDBDBD` |

## 2. LLM 标注规范

对每个词输出严格 JSON：

```json
{ "emotion_type": "sadness", "emotion_intensity": 0.72 }
```

- `emotion_type` 必须属于上述 9 类之一。
- `emotion_intensity` ∈ [0,1]；`neutral` 时强度应接近 0。
- 一词可含多重情绪时，取**主导情绪**为类型，强度取其强度。

### Prompt 模板（示意）

```
你是情绪标注器。对给定词语，判断其最主导的情绪类型与强度。
情绪类型限定为：joy, trust, fear, surprise, sadness, disgust, anger, anticipation, neutral。
只输出 JSON：{"emotion_type": "...", "emotion_intensity": 0.0~1.0}
词语：房子
```

## 3. 后续扩展

- 词典优先 + LLM 兜底（大连理工情感本体等）可在 `emotion_scheme` 中扩展。
- 强度可进一步映射到可视化中的节点大小/饱和度。
